## Android 동작 경계

- 라이브 라디오이므로 이전 곡/다음 곡/타임라인 탐색 명령은 공개하지 않습니다.
- 사용자가 중지한 뒤 네트워크가 살아나거나 오래된 HTTP 결과가 도착해도 자동 재생하지 않습니다.
- 이어폰 분리나 오디오 포커스 손실로 멈춘 재생은 사용자가 다시 재생할 수 있습니다.
- OS 강제 종료 뒤 자동 재생, 부팅 자동 시작, Android Auto 브라우징 및 Cast는 포함하지 않습니다.
- 메타데이터는 방송 서버의 현재 곡입니다. 오디오 버퍼 지연만큼 실제 들리는 곡과 몇 초 차이 날 수 있습니다.
- 알림의 커스텀 종료 버튼과 앨범아트 위치는 시스템/제조사가 결정합니다.
- API/알림/백그라운드 재생의 실제 동작은 아직 기기 검증 전입니다.
